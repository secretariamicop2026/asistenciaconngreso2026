IMPORTAR
Cargar tu lista de invitados

Columnas esperadas: nombre, apellidos, dni, zona (0 al 7) y sexo (M/F o Masculino/Femenino) — todas opcionales excepto nombre y dni, con encabezado en la primera fila. Descargar plantilla

O pega la lista a mano, una persona por línea, formato: DNI,Nombre,Apellidos,Sexo,Zona (Apellidos, Sexo y Zona son opcionales)

Todo se guarda en una base de datos real (Firebase) y se sincroniza en vivo con cualquiera que tenga este mismo link abierto.

FOTOS
Subir fotos de los miembros

Selecciona muchas fotos a la vez. El sistema empareja cada foto por el nombre del archivo (ej. Daniel Montalvan Ruiz.jpg) o por el DNI (ej. 70533839.jpg). Si subes una carpeta con subcarpetas llamadas "Zona 1", "Zona 2"…, busca cada foto solo dentro de esa zona. También puedes subir una por una tocando el círculo de la persona en el Registro.

CREDENCIALES
Imprimir credenciales con código QR

Genera una hoja lista para imprimir, con el número, nombre y código QR de cada invitado (para recortar y repartir como credencial antes del evento).

ZONA DE PELIGRO
Reiniciar lista completa

Esto borra TODOS los invitados y sus marcas de llegada, para empezar de cero (por ejemplo, si vas a cargar una lista totalmente nueva para otro evento). Esta acción no se puede deshacer.
